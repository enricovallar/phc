# phc-mpb

General Photonic Crystal band structure solver and GDS converter based on MIT Photonic Bands (MPB).

## Features
- **General Lattice Support**: Hexagonal/triangular and square/rectangular lattices.
- **Dimensionality**: 2D infinite and 3D finite-thickness slabs (with light cone).
- **Polarizations**: 2D TE/TM and 3D slab even (TE-like) and odd (TM-like) mirror modes.
- **SSOT Integration**: Directly converts GDS files or GDSfactory components into MPB geometric objects.
