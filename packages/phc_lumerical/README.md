# phc-lumerical

Ansys Lumerical FDTD/MODE simulation automation and GDS import for Photonic Crystals.

## Status: Planned (TODO)
This package is scaffolded as part of the Single Source of Truth (SSOT) architecture. It will house:
- `lumapi.FDTD` and `lumapi.MODE` session management.
- Method A material database loading (`materials/custom_materials.mdf`).
- Direct GDS import (`lumapi.gdsimport`) using `LayerStack` extrusions.
