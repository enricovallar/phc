# `phc_lumerical` Guidelines & Rules

## Scope
`phc_lumerical` provides Python automation for Ansys Lumerical FDTD and MODE simulations, automated GDSII geometry import, and boundary/mesh configuration for photonic crystals.

## Core Rules

1. **Session & API Management**:
   - Communicate with Lumerical via the official `lumapi` module (`lumapi.FDTD()` or `lumapi.MODE()`).
   - If `lumapi` cannot be imported or a Lumerical license is unavailable, fail cleanly with an informative error rather than generating fake simulation results.
   - Always guarantee clean cleanup of solver sessions using context managers (`with FDTDSession() as fdtd: ...`).

2. **Material Integration (Method A)**:
   - Materials must be sourced from `phc_materials`.
   - Map materials either by looking up standard names in Lumerical's database (`mat.lumerical_name`), or by programmatically exporting and loading `.mdf` (Material Data Format) files.
   - Never define custom refractive indices directly in Lumerical scripts without registering them in `phc_materials`.

3. **GDS Import & LayerStack Extrusion**:
   - Utilize Lumerical's GDS import API (`fdtd.gdsimport(...)`) to load GDS layouts generated by `phc_layout`.
   - Define a `LayerStack` mapping GDS `(layer, datatype)` pairs to vertical coordinates (`z_min`, `z_max`) and material keys from `phc_materials`.

4. **Boundary & Symmetry Conditions**:
   - PhC unit cell transmission/reflection/resonance simulations: Use Bloch / periodic boundary conditions in $x$ and $y$, and PML (Perfectly Matched Layer) in $z$.
   - Finite PhC waveguides/cavities: Use PML on all absorbing boundaries.
